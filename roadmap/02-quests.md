# Этап 02 — Квесты

Связано с игровым дизайном: [`Квесты`](../docs/game-design/02-quests.md).

## Цель

Дать игроку способ реально зарабатывать XP и золото через ежедневные действия
(квесты), а не только через `/start`. Это первое взаимодействие "команда бота → изменение
состояния игрока в БД".

## Текущее состояние

Бот умеет обрабатывать только один текст сообщения — `/start`, через `if text == "/start"`
в `HandleMessage`. Никакого разбора команд с аргументами, никакого списка квестов ещё нет.

## Задачи

1. **Завести тип `Quest`** в `internal/models`:
   ```go
   type Quest struct {
       ID          int
       Name        string
       Description string
       XPReward    int
       GoldReward  int
   }
   ```

2. **Каталог квестов.** Для старта не обязательно хранить квесты в БД — можно завести
   простой каталог прямо в коде как `slice`:
   ```go
   var QuestCatalog = []Quest{
       {ID: 1, Name: "Прочитать статью", XPReward: 20, GoldReward: 5},
       {ID: 2, Name: "Решить задачу", XPReward: 30, GoldReward: 10},
       {ID: 3, Name: "Сделать коммит", XPReward: 50, GoldReward: 15},
   }
   ```
   Хранение "в базе" понадобится позже, когда квесты станут динамическими
   (см. [этап 08](08-elite-bosses-infra.md) про миграции) — для MVP хардкод в коде это
   абсолютно нормальная практика.

3. **Команда `/quests`** — показать список доступных квестов игроку (пройтись циклом
   `for _, q := range QuestCatalog` и собрать текст).

4. **Команда `/done <id>`** — засчитать квест: распарсить аргумент, найти квест по ID,
   начислить XP и золото игроку, сохранить в БД, ответить сообщением.

5. **Разбор команд с аргументами.** Сейчас `HandleMessage` сравнивает текст напрямую
   (`text == "/start"`). Для `/done 2` понадобится:
   ```go
   parts := strings.Fields(text) // ["/done", "2"]
   if len(parts) >= 2 && parts[0] == "/done" {
       questID, err := strconv.Atoi(parts[1])
       if err != nil {
           bot.Send(tgbotapi.NewMessage(userID, "Не понимаю номер квеста 🤔"))
           return
       }
       // ...
   }
   ```
   Если команд станет больше двух-трёх — стоит подумать про `switch` по первому слову
   вместо цепочки `if`.

6. (Опционально, но полезно) **Простая защита от повторного зачёта** ежедневного квеста —
   например, таблица `quest_log (player_id, quest_id, done_at)`, чтобы один и тот же квест
   нельзя было засчитать 100 раз подряд за один день.

## Go-концепции

**Срезы (slices).** `[]Quest{...}` — это срез, динамический список элементов одного типа.
В отличие от массивов фиксированного размера, срез может расти (`append`). `for _, q := range QuestCatalog`
— идиоматичный способ перебрать все элементы; `_` означает "мне не нужен индекс, только
значение".

**Множественный возврат и обработка ошибок.** `strconv.Atoi` возвращает `(int, error)` —
это стандартный для Go паттерн: функция, которая может не получиться, возвращает результат
и ошибку отдельно, вместо исключений (exceptions), которых в Go нет. Правило: сразу после
вызова такой функции проверяй `if err != nil`, и решай, что делать — вернуть ошибку выше
(`return err` / `return nil, err`) или обработать на месте (как в примере выше — сообщить
пользователю и выйти из функции).

**Пакет `strings`.** `strings.Fields(text)` бьёт строку по пробелам и убирает лишние —
удобно для разбора простых команд. Позже, если команд станет много, можно посмотреть на
готовые библиотеки для Telegram-команд, но для нескольких команд ручной разбор — это
нормально и даже полезно для практики.

**Именованные константы для команд** — вместо строк `"/start"`, `"/quests"`, `"/done"`
россыпью по коду, стоит завести:
```go
const (
    cmdStart  = "/start"
    cmdQuests = "/quests"
    cmdDone   = "/done"
)
```
Это пример использования `const` и хорошего тона — меньше шанс опечататься в строке.

## Готово, когда...

- `/quests` показывает список из каталога с наградами.
- `/done <id>` реально начисляет XP и золото и меняет данные в БД (проверяется через `/start`
  после — должны быть видны новые XP/Gold).
- Неверный/несуществующий ID квеста не роняет бота, а вежливо сообщает об ошибке.
