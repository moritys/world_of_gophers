# 🗺️ Roadmap проекта World of Gophers

Это план разработки бота, разбитый на этапы. Он построен так, чтобы совпадать с твоим же
игровым дизайном ([`/docs/game-design`](../docs/game-design/README.md)): каждый этап — это
примерно один "уровень" или "глава" игры, и одновременно — порция реального Go, которую ты
осваиваешь. Проверка навыка = "босс" в игре = завершённый этап здесь.

Так как ты только изучаешь Go, в каждом файле этапа есть не только список задач, но и
раздел "Go-концепции" с объяснением, что это такое и зачем оно нужно именно в этом месте
кода. Не обязательно проходить всё за один присест — можно возвращаться к этим файлам как
к шпаргалке.

## Как читать этапы

Каждый файл `NN-название.md`:
1. **Цель** — что мы добавляем в игру и зачем.
2. **Текущее состояние** — что уже есть в коде прямо сейчас (чтобы не гадать).
3. **Задачи** — конкретные шаги, обычно с примерами кода.
4. **Go-концепции** — объяснение новых для новичка вещей Go, которые встретятся на этом этапе.
5. **Готово, когда...** — критерий, что этап закрыт (свой "босс повержен").

## Текущее состояние проекта (на момент составления этого roadmap)

Уже реализовано:
- Каркас Telegram-бота на `go-telegram-bot-api`, поллинг апдейтов (`cmd/bot/main.go`).
- Подключение к PostgreSQL через `pgx/v5` + `pgxpool` (`internal/database/db.go`).
- Таблица `player` (`id`, `name`, `level`), функции `CreatePlayer` и `GetUserByID`.
- Команда `/start`: если игрок новый — создаётся и получает приветствие; если уже
  существует — получает приветствие "с возвращением".
- Docker + docker-compose для локального запуска бота и базы.

Ещё не реализовано (и это как раз содержание этапов ниже): XP и золото не сохраняются
и не начисляются по-настоящему (`ReturnText` сейчас всегда показывает `XP: 0, Gold: 0` —
это просто текст-заглушка, не значение из БД); нет квестов, ачивок, боссов, серии дней,
магазина, HTTP-эндпоинтов, тестов, миграций.

## Порядок

Этапы 01–06 — это "Глава 1: Ученик Go" из игрового дизайна: структуры, методы, немного
интерфейсов, первые кусочки конкурентности. Они целиком крутятся вокруг уже существующего
Telegram-бота и БД, ничего принципиально нового по инфраструктуре не требуют — то есть это
самая безопасная часть, чтобы освоиться.

Этапы 07–09 — это уже "Глава 2–4": здесь появляется HTTP, тесты, миграции, Docker
по-взрослому. Не обязательно идти строго по порядку номеров внутри 07–09, но 01–06 лучше
пройти именно последовательно, потому что квесты и боссы используют то, что появится в
"Герое" на этапе 01.
