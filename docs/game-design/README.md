## Игра сюжетная!

Проект оформлен как RPG про обучение Go: ты — гофер (гоферка 🐹), который проходит путь от
ученика до кандидата на стажировку. Каждая глава истории привязана к реальному разделу Go/backend,
который нужно освоить.

🌱 **Глава 1 — Ученик Go**
- структуры
- методы
- интерфейсы

🏹 **Глава 2 — Backend-подмастерье**
- HTTP
- JSON
- роутинг

⚔️ **Глава 3 — Хранитель данных**
- SQL
- PostgreSQL
- миграции

👑 **Глава 4 — Кандидат на стажировку**
- Docker
- тесты
- финальный проект

И финальный рейд-босс:

🐲 **Собеседование на стажировку**
